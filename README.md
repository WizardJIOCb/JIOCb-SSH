# Лось SSH

Скачайте **LosSSH-Windows-x64.zip** из [релизов](https://github.com/WizardJIOCb/JIOCb-SSH/releases), распакуйте архив и запустите **Лось SSH.exe**. При первом запуске откроется PowerShell. После закрытия окна приложение автоматически восстанавливает вкладки, их порядок, названия, выбранную вкладку и раскладку панелей. Кнопка **+** в полосе вкладок открывает меню подключений и панелей.

SSH-панели, открытые через меню, при восстановлении создают новые подключения к прежним серверам. За вход отвечает OpenSSH, поэтому сервер может снова запросить пароль или подтверждение. Команды и вывод прошлой сессии остаются в завершённом процессе. Вкладка PowerShell открывается в домашней папке.

Раскладки хранятся в `%LOCALAPPDATA%\LosSSH`. Для одновременно запущенных копий приложения выделяются отдельные файлы.

Для подключения нажмите **Ctrl+Shift+S**. Введите часть имени из файла `%USERPROFILE%\.ssh\config` и нажмите Enter. Чтобы подключиться по адресу, выберите «Ввести адрес SSH…». Можно ввести `dev@server` или `dev@server 2222`. Ключи, SSH-агент и проверку ключа сервера обслуживает системный OpenSSH.

| Действие | Клавиши |
| --- | --- |
| Открыть меню | Ctrl+Shift+K |
| Подключиться по SSH в новой вкладке | Ctrl+Shift+S |
| Открыть вкладку PowerShell | Ctrl+Shift+T |
| Разделить панель вправо / вниз | Ctrl+Shift+D / Ctrl+Shift+E |
| Перейти в соседнюю панель | Alt+стрелка |
| Передвинуть границу панели | Alt+Shift+стрелка или мышь |
| Развернуть панель / вернуть раскладку | Ctrl+Shift+Z |
| Найти текст в выводе | Ctrl+Shift+F |
| Переименовать вкладку | F2 |
| Перейти к следующей / предыдущей вкладке | Ctrl+Tab / Ctrl+Shift+Tab |
| Закрыть активную панель | Ctrl+Shift+W |

При разделении SSH-панели, открытой через меню, создаётся ещё одно соединение с тем же сервером. Чтобы открыть другой сервер рядом, выберите «Другой SSH-сервер справа». При разделении локальной панели открывается ещё один PowerShell.

## Сборка

Для запуска нужны Windows x64 с .NET Framework 4.x и системным клиентом OpenSSH. Для переноса на другой комп скопируйте папку приложения целиком.

Чтобы собрать приложение из исходников, выполните в PowerShell из папки проекта

```powershell
.\build.ps1
```

Скрипт скачает портативный WezTerm, проверит SHA256 архива и соберёт C#-лаунчер. Цвета, размер шрифта, горячие клавиши и объём истории задаются в `los-ssh.lua`. [Исходный код движка WezTerm](https://github.com/wezterm/wezterm/tree/20240203-110809-5046fc22)
